SoloStars API

Telegram Stars va Telegram Premium buyurtmalarini o‘z saytingiz yoki botingizdan to‘g‘ridan-to‘g‘ri yuboring. Barcha so‘rovlar JSON formatida ishlaydi.

Eslatma: quyidagi manzil va maydonlar namuna. Bot backend’ingizdagi haqiqiy endpoint’larga moslab, BASE_URL ni almashtiring.

Boshlash

Asosiy manzil:

https://api.solostars.uz/v1

API kalitni olish uchun @solostarsuz_bot ga kiring, /api buyrug‘ini yuboring. Bot sizga kalit beradi. Kalitni hech kimga bermang.

Tezkor sinov:

curl https://api.solostars.uz/v1/balance \
  -H "Authorization: Bearer YOUR_API_KEY"

Avtorizatsiya

Har bir so‘rovda Authorization sarlavhasi bo‘lishi shart:

Authorization: Bearer YOUR_API_KEY
Content-Type: application/json

Kalit noto‘g‘ri bo‘lsa, 401 invalid_api_key qaytadi.

Webhook

Buyurtma holati o‘zgarganda tizim sizning URL’ingizga POST so‘rov yuboradi. URL’ni botdagi /api bo‘limida kiriting.

{
  "event": "order.completed",
  "order": {
    "id": "ord_8f3k2a",
    "type": "stars",
    "username": "durov",
    "amount": 100,
    "status": "completed"
  }
}

Voqealar: order.completed, order.failed, order.refunded. Serveringiz 200 qaytarishi kerak, aks holda so‘rov 3 marta qayta yuboriladi.

So‘rovning haqiqiyligini tekshirish uchun X-Signature sarlavhasi yuboriladi. Bu tanadan API kalit bilan olingan HMAC-SHA256:

import hmac, hashlib

def valid(body: bytes, signature: str, api_key: str) -> bool:
    calc = hmac.new(api_key.encode(), body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(calc, signature)

Limitlar

Har bir kalit uchun daqiqasiga 60 ta so‘rov. Oshib ketsa 429 va Retry-After sarlavhasi qaytadi. Bir xil order_id bilan qayta yuborilgan so‘rov yangi buyurtma yaratmaydi, avvalgisini qaytaradi.
